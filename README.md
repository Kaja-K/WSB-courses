# WSB Courses

Coursework from WSB Merito Wrocław — M.Sc. in Economic Analytics and Data Analysis (spec. Business Intelligence).

## Courses

| Semester | Folder | Tools | Description |
|----------|--------|-------|-------------|
| 1 | `database-systems` | T-SQL | Database systems — querying, aggregation, joins, DDL, date functions and subqueries |
| 2 | `analyst-work-environment` | Python, R | Analyst work environment — tools, workflows and data processing |
| 2 | `data-mining` | Python | Data mining for economic analytics — CRISP-DM, ETL|

## Tools

## About

Each course folder contains its own materials. Labs follow a consistent workflow: understand the problem, explore and prepare the data, analyze, and finish with a short business conclusion.
